A COMPUTER-IMPLEMENTED TIME-SERIES FORECASTING SYSTEM

Officially published in The Patent Office Journal No. 1/2026 (Dated 02/01/2026, Page 385) under the Government of India Patent Office. The invention details a state-of-the-art hybrid predictive system combining statistical AutoRegressive Integrated Moving Average (ARIMA) and deep recurrent Long Short-Term Memory (LSTM) Neural Networks with automated sliding-window sequence generators for high-precision temporal projections.

Official Gazette Abstract (Record 57) Published with Figure 1

"A computer-implemented time-series forecasting system (100) receives sequential time-series data via input module (101, 201). Data-splitting module (102, 203) divides it into training and testing datasets, with preprocessing module (202) normalizing, scaling, smoothing, or differencing data. Dataset-creation module (204) generates supervised sequences using sliding-window mechanisms for LSTM model module (205), while ARIMA model module (103) determines parameters (p, d, q). Model-training module (104, 206) trains both models on training data. Prediction module (105, 207) produces outputs, inverse-transformed by module (208) to original scale. Error-metrics module (107, 209) computes accuracy using actual values from module (106). Future-forecast module (108) enables multi-step projections, enhancing hybrid forecasting precision."

⚙️ Claimed System Subsystems & Modular Architecture

Overview of the 6 key modules as detailed in the official patent specification and Figure 1:

Module 101, 201
Sequential Time-Series Input

Receives multi-variate sequential financial time-series streams and structures temporal timestamps for downstream processing.

Module 102, 202, 203
Data Partitioning & Preprocessing

Normalizes, scales, smooths, and differences data to isolate stationary trends from stochastic market noise.

Module 204
Sliding-Window Dataset Creation

Generates supervised sequence matrices using sliding temporal windows optimized for deep recurrent backpropagation.

Module 103, 205
Hybrid ARIMA + LSTM Dual Core

ARIMA dynamically determines (p, d, q) parameters for linear trends while the LSTM captures complex non-linear residual sequences.

Module 104, 105, 206, 207
Parallel Training & Prediction

Trains both architectures concurrently on the partitioned training data and generates synchronized predictive vectors.

Module 107, 108, 208, 209
Inverse-Transform & Error Verification

Maps predictions back to real market scale, calculates RMSE/R² accuracy metrics, and enables robust multi-step forward forecasting.
